Aster برای ویندوز — نصب و آپدیت

۱. Aster-Setup-x64.exe را برای کامپیوتر Intel/AMD، یا Aster-Setup-ARM64.exe را برای ویندوز ARM اجرا کنید.
۲. دسترسی Administrator را بپذیرید. برنامه و میان‌برها نصب می‌شوند؛ در صورت نیاز WebView2 هم نصب می‌شود.
۳. برنامه را باز کنید و از Servers → Import تنظیمات خود را وارد کنید.
۴. سرور را انتخاب کنید و Connect را بزنید.

برای آپدیت: Settings → Application updates → Check for updates
اگر نسخه جدید موجود باشد، Download & install را بزنید. برنامه فایل را دانلود و امضای آن را بررسی می‌کند، سپس خودش نصب و دوباره باز می‌شود.
تنظیمات و سرورها حفظ می‌شوند. هنگام نصب آپدیت، VPN برای مدت کوتاهی قطع می‌شود.

نسخه قدیمی 0.1.0 را یک‌بار با همین نصب‌کننده ارتقا دهید. اگر برنامه قدیمی باز است، از منوی کنار ساعت Quit را بزنید.
بستن پنجره، Aster را کنار ساعت نگه می‌دارد. Quit، VPN را قطع می‌کند.

فایل‌های ZIP برای اجرای قابل‌حمل هم موجود هستند: کل پوشه را استخراج کنید و Aster.exe را اجرا کنید.
خود برنامه و نصب‌کننده امضای تجاری ویندوز ندارند؛ اصالت آپدیت‌های داخل برنامه با امضای Ed25519 بررسی می‌شود.
